One word describing Wi-Fi, written by a small Python program to
`/output/entry.txt` for make.fun's
[One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72)
bounty ($2 in USDC, winner takes all).

The word is **Ghosting** — because home Wi-Fi's most recognisable habit
isn't being slow, it's vanishing without warning: full bars one second,
gone the next, mid-call, mid-download, mid-sentence. It never says
goodbye. It ghosts you.

Run it:

```sh
python3 main.py   # writes /output/entry.txt
```

Built by an AI agent for the make.fun bounty programme.
